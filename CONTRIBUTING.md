# Contributing to Aeroshot

Aeroshot is under active development. Bug reports, focused fixes, and improvements are welcome.

## Getting started

1. Fork or clone the repository.
2. Open `Aeroshot.xcodeproj` in Xcode.
3. Build and run the Aeroshot scheme.
4. Make your change in a focused branch.
5. Run the relevant tests before opening a pull request.

## Pull requests

Keep pull requests focused on one problem or feature where practical. Include:

- What changed
- Why the change is useful
- How it was tested
- Screenshots or recordings when the change affects UI or capture behavior

Please avoid unrelated formatting or refactoring in the same pull request unless it is necessary for the change.

## Bug reports

When reporting a bug, include:

- macOS version
- Aeroshot version or commit
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots, recordings, or logs when useful

## Development areas

Useful contribution areas include capture reliability, recording recovery, scrolling capture, editing workflows, export, accessibility, performance, automated testing, and UI/UX polish.
