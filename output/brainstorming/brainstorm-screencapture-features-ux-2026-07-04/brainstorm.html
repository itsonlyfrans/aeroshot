4 Worst Possible Idea → Flipped

Anti-patterns mined for polish wins.

12 permission dialogs every capture→Single unified permission wizard
Scrolling buried in Recording→Dedicated Scrolling pane or clear section
Overview duplicates Capture toggles→Overview read-only dashboard
Recordings missing from History→Recordings tab alongside Images/Text
Beautify settings lost each session→Persist defaults in SettingsStore

★ Convergence — Two Tracks

Impact–effort sort: polish sprint first, feature epics second.

Polish Sprint (ship first)

  • Overview read-only + remove duplicate toggles
  • Permission wizard on first launch
  • Split/relabel Scrolling vs Recording settings
  • Selection overlay W×H dimensions
  • Recordings tab in History
  • Menu bar icon status variants
  • Reset settings + export/import profile
  • Editor Settings pane (beautify persistence)

Feature Backlog (competitive bets)

  • Named capture profiles (Bug Report, Social, Docs)
  • Filename templates with smart tokens
  • macOS Shortcuts actions per intent
  • Quick Share + optional cloud URL
  • Delay timer + last-region recall
  • Mic/webcam recording overlays
  • Ruler + annotation templates in editor
  • AppleScript + per-app hotkey profiles
