# WP-00 security and privacy status

- No application behavior, permissions, entitlements, network calls, logging, or data storage changed in WP-00.
- Golden workflows must include permission denial, cancellation, recovery, and local-only exits.
- Future event tracks for cursor/click/keystroke/webcam data remain planned, not implemented. Keystroke capture must be opt-in, visibly indicated, deletable, excluded from secure-input contexts, and excluded from diagnostics.
- Local capture, editing, reopen, and export must remain usable without an account or cloud service.
- No security or privacy audit is claimed complete; this is the Phase 0 contract only.
